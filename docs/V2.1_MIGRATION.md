## Current scope
This branch introduces tested, UI-independent domain primitives. The existing `index.html` remains untouched, and **its buttons are not yet wired to these modules**. The production site is not upgraded by this commit.

## Acceptance gates
1. Run `npm test` using Node.js 20+.
2. Verify deterministic replay and shipment transition tests pass.
3. Integrate modules behind a feature flag, then add UI and E2E tests.
4. Replace placeholder concurrency, optimizer, decoder, and e-POD claims only after real implementations and evidence exist.
5. Do not merge into main until preview deployment and mobile testing pass.
