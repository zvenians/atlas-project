## v2.1 Architecture Overview

1. **Deterministic Simulation Core (`src/core/simulation.js`)**:
   - Seeded pseudo-random simulation loop for vehicle tracking.
   - Deterministic speed scaling (1x, 2x, 4x), tick advancing, and state pause/play controls.
   - Event subscription pattern for UI rendering synchronisation.

2. **Shipment Primitives & Transitions (`src/core/shipments.js`)**:
   - Explicit state machine: `CREATED` -> `DISPATCHED` -> `IN_TRANSIT` -> `DELIVERED`.
   - CSV parsing with strict validation, error reporting, and export capabilities.

3. **Legacy Bridge & 3D Tactical Viewport (`src/legacy-integration.js`)**:
   - Connects index.html DOM elements to core simulation and shipment state machines.
   - Injects 3D camera controls, 3D extruded hub towers, vehicle elevation poles, and 3D cargo bay digital twin.

## 3D Tactical Viewport Features

- **3D Camera Control Toolbar (`#atlas-3d-camera-bar`)**:
  - Interactive mode toggle between 3D Pitch (48°) and 2D Orthogonal (0°).
  - Tilt adjustment (`rotateX(16deg..64deg)`).
  - Orbit rotation controls (`rotateZ`).
  - Zoom controls (`perspective(1150px)` scale adjustment).
- **Extruded Volumetric Hub Towers**:
  - 3D polygon menara with ground radar rings at Kariangau, Somber, MT Haryono, Semayang, Sepinggan, and KM 13 hubs.
- **Vehicle Elevation Poles**:
  - Vertical 3D dashed elevation lines and illuminated beacon heads on vehicle map markers.
- **3D Cargo Bay & Thermal Digital Twin**:
  - Fleet inspection panel card (`#cargo-bay-digital-twin`) rendering an isometric 3D container wireframe, capacity-proportional cargo pallet blocks (Copper `#DCA876` and Teal `#65C9B6`), and real-time reefer thermal readouts.
